# cozybox.nvim

A darker gruvbox with blue accents, a softer red, and a light mode.

## Dark
<img width="1800" height="1131" alt="cozybox dark" src="docs/assets/cozybox-dark.png" />

## Light
<img width="1800" height="1131" alt="cozybox light" src="docs/assets/cozybox-light.png" />

## Use

```vim
colorscheme cozybox       " dark
colorscheme cozybox-light " light
```

There are no options. To change a colour, edit the palette in `lua/cozybox.lua`.
